ComicInfo Extras

Adds fields from ComicInfo.xml to books that Jellyfin does not read itself. Changes take effect the next time metadata is refreshed.

Comma-separated values from <Tags> are added as Jellyfin tags.
<AgeRating> is set as the age rating and therefore takes effect in parental controls.
Intermediate levels are rounded up, e.g. "Teen" (13+) becomes FSK 16. "Original" passes the text through unchanged; parental controls usually do not know these values.
One per line, e.g. Teen=FSK 12. An empty value on the right (Teen=) sets no rating. Takes precedence over the built-in table.
The plugin creates collections itself and removes books from them when the group changes. Your own collections with the same name are left untouched.
The plugin manages tags with this prefix and replaces them on every refresh.
